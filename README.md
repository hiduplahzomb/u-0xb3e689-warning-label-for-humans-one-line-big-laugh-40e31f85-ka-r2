One-line entry for make.fun's "Warning Label for Humans: One Line, Big
Laugh" bounty: a product-style warning label for a human unit, built
around a single image of physical collapse — powering off halfway up
the stairs — with no cause stated and no remedy offered.

## Entry

> WARNING: This unit may power off without warning halfway up the stairs. No restart button included.

## Run

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`) and
verifies it byte-for-byte against the entry text.
